# PMTUML
# (Predicting Molecular Toxicity Using Machine Learning) PMTUML

In short, this repository will be used to demonstrate how an AI model can be trained to predict the toxicity (how well/poorly a molecular will bind to twelve human receptor, namely NR-AR, NR-AR-LBD, NR-AhR,NR-Aromatase, NR-ER, NR-ER-LBD,NR-PPAR-gamma, SR-ARE, SR-ATAD5,SR-HSE, SR-MMP, and SR-p53) of a molecule (given a molecular formula of the SMILES style) with the potential of providing insights on how certain drug families affect specific receptors in the human body.
